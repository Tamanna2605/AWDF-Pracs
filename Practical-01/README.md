# Student Portfolio — Practical 1

A simple student portfolio built using React functional components and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually http://localhost:5173).

## Components

- `Header`: displays the student's name and site title; receives `name` and `themeColor` props.
- `NavBar`: navigation links for the page sections.
- `About`: displays a short introduction; receives the `description` prop.
- `Skills`: renders a skills array received through the `skillList` prop.
- `Projects`: renders three sample projects.
- `Footer`: displays contact and copyright information; receives the `email` prop.

## Build check

```bash
npm run build
```
