# Practical 2 – React Router and useState

This project extends the Practical 1 student portfolio with client-side routing and React state.

## Run the project

```bash
npm install
npm run dev
```

## Routes

- `/` – Home page
- `/projects` – Projects page
- `/contact` – Controlled contact form
- `*` – Custom 404 page

## Concepts demonstrated

- `BrowserRouter`, `Routes`, and `Route`
- `Link` and `NavLink` for navigation without full page reloads
- `useState` for dark/light theme, help visibility, and contact input
- Controlled form input with live character count
- Reusable Header, NavBar, Footer, and project cards

## Production build

```bash
npm run build
```
